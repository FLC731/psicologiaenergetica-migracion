# Migración de psicologiaenergetica.net

Reconstrucción independiente y progresiva de la web pública https://www.psicologiaenergetica.net/. **Trabajo en curso: todavía no es una réplica completa ni está desplegada.**

## Criterios
- Conservar en lo posible el contenido, las rutas y la estética originales.
- Solo si un elemento visual de Wix no se puede reproducir, tomar https://www.felixlarriba.com/ como referencia secundaria.
- No modificar la web Wix publicada ni el dominio.
- Este repositorio es público: no incluir datos de usuarios, formularios recibidos, credenciales ni contenido no publicado.

## Estado comprobado
- Se han identificado 21 entradas publicadas mediante la API de Wix, pero todavía no se han incorporado sus cuerpos completos.
- La API de SEO ha identificado páginas como `/trauma`, `/psicoenergetica`, `/reservar-online` y `/suscripción`; no constituye aún un inventario completo.
- Faltan la reconstrucción de páginas, imágenes, navegación, blog y comprobación de funciones en móvil y escritorio.

No confundir este repositorio inicial con una migración terminada.
